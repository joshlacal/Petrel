# StatusphereOverlay — Custom ATmosphere Lexicon Example

`StatusphereOverlay` demonstrates how to build an ATmosphere application with **custom Lexicon schemas** (`xyz.statusphere.status` and `xyz.statusphere.getStatuses`) compiled into a standalone Swift 6 overlay library (`PetrelStatusphere`) on top of `Petrel`.

## Layout

```text
Examples/StatusphereOverlay/
├── Package.swift                                  # PetrelStatusphere library + StatusphereCLI executable
├── petrel-manifest.json                           # Overlay codegen manifest ("kind": "overlay")
├── lexicons/
│   └── xyz/statusphere/
│       ├── status.json                            # Custom record schema (xyz.statusphere.status)
│       └── getStatuses.json                       # Custom AppView query referencing app.bsky.actor.defs
└── Sources/
    ├── PetrelStatusphere/Generated/               # Generated by Petrel's lexicon code generator
    │   ├── Client/
    │   │   ├── ATProtoClient+PetrelStatusphere.swift
    │   │   └── PetrelStatusphereLexicons.swift
    │   └── Lexicons/Xyz/Statusphere/
    │       ├── XyzStatusphereGetStatuses.swift
    │       └── XyzStatusphereStatus.swift
    └── StatusphereCLI/
        └── StatusphereCLI.swift                   # Offline round-trip demo + live PDS read/write CLI
```

## Quick Start (Zero Credentials Required)

Run the self-contained verification demo to construct a typed `XyzStatusphereStatus` record, encode it to canonical JSON and deterministic DAG-CBOR, compute its `CIDv1` hash, and hydrate wire JSON dynamically through `ATProtocolValueContainer` after calling `PetrelStatusphereLexicons.register()`:

```bash
cd Examples/StatusphereOverlay
swift run StatusphereCLI --demo
```

## Reading & Writing Live Custom Records on Any PDS

Inspect `xyz.statusphere.status` records stored in any AT Protocol user's Personal Data Server (resolving their handle bidirectionally via `IdentityResolver` first):

```bash
cd Examples/StatusphereOverlay
swift run StatusphereCLI list --actor atproto.com
```

Publish a custom `xyz.statusphere.status` record to your own PDS repository (prompts securely with terminal echo disabled for a scoped App Password):

```bash
cd Examples/StatusphereOverlay
swift run StatusphereCLI post \
  --handle your-handle.bsky.social \
  --emoji "🚀" \
  --mood "xyz.statusphere.defs#shipping" \
  --note "Testing custom Lexicon overlays with Petrel 2.0"
```

## Regenerating the Overlay

From the Petrel repository root:

```bash
python3 run.py --manifest Examples/StatusphereOverlay/petrel-manifest.json --language swift
swiftformat Examples/StatusphereOverlay/Sources/PetrelStatusphere/Generated
```

In your own external repository, install `petrel-gen` (or invoke the `petrel-codegen` SwiftPM command plugin) so you never need a local clone of Petrel's repository.
