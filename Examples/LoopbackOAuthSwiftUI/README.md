# LoopbackOAuthSwiftUI — Reference SwiftUI OAuth + Timeline Starter

`LoopbackOAuthSwiftUI` is a complete Swift 6 + SwiftUI reference starter demonstrating how to integrate `Petrel` into a macOS or iOS application:

- **Zero-Deploy Localhost Development (`OAuthConfig.loopback(port: 8765)`)**: Uses an ephemeral `127.0.0.1:8765` `NWListener` (`LoopbackCallbackServer`) to complete a real PAR + PKCE + DPoP OAuth 2.1 login without deploying a `client-metadata.json` document or tunnel.
- **Production Custom-Scheme Mode (`WebAuthenticationSession`)**: Switches cleanly to an `https://.../oauth-client-metadata.json` configuration paired with SwiftUI's `@Environment(\.webAuthenticationSession)` (`ASWebAuthenticationSession`), and previews the exact `oauth-client-metadata.json` generated by `OAuthConfig.clientMetadataDocument(...)`.
- **Keychain Session Persistence**: Restores the signed-in DPoP-bound session automatically across launches via `hasValidSession()` and `getActiveAccountInfo()`.
- **RichText Composer & Timeline**: Fetches and paginates `app.bsky.feed.getTimeline`, renders `RichText(post:)` segments with highlighted mentions/links/tags, previews live UTF-8 byte & 300-grapheme limits while typing, and publishes posts via `client.bsky.post(...)`.

## Build & Run

```bash
cd Examples/LoopbackOAuthSwiftUI
swift build
swift run LoopbackOAuthSwiftUI
```

To embed the UI inside an Xcode `.xcodeproj` for iOS Simulator or physical devices, import the `LoopbackOAuthFeature` library target and mount `RootContentView()` inside your app's `WindowGroup`, registering your custom URL scheme (`com.example.atmosphere`) in `Info.plist` when switching from Loopback Dev to Production Custom Scheme mode.
